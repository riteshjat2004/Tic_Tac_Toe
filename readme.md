# Tic Tac Toe Game

A responsive and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**.  
The project focuses on clean UI design, smooth gameplay, and compatibility across different screen sizes.

## Features
- Responsive design for desktop and mobile devices
- Two-player gameplay (X vs O)
- Real-time win and draw detection
- Simple and user-friendly interface
- Restart game functionality

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Play
1. Open the game in a web browser.
2. Players take turns clicking on the grid to place **X** or **O**.
3. The game announces the winner or a draw.
4. Click the restart button to play again.
